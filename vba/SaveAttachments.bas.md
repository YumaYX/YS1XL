# SaveAttachments

- 目的: 指定した Outlook メールフォルダ内のメールに添付された、キーワードを含むファイルを保存する。

# 入力（日本語）

| 引数名          | 型     | 説明                               |
|-----------------|--------|------------------------------------|
| mailFolderPath  | String | メールフォルダ（ルートからのパス） |
| targetFolderPath| String | 保存先フォルダ                     |
| keyword         | String | 添付ファイル名のキーワード         |

# 出力（日本語）

- 型: なし（Sub）
- 内容: 条件に一致する添付ファイルを保存先へ書き出す（同名既存ファイルはスキップ）。

# 使用例

```vba
Call SaveAttachments("アーカイブ", "C:\Temp", "キーワード")
```
