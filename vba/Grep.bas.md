# Grep

- 目的: 指定列を走査し、キーワードに一致するセルの値をイミディエイトウィンドウに出力する。

# 入力（日本語）

| 引数名              | 型        | 説明                                   |
|---------------------|-----------|----------------------------------------|
| ws                  | Worksheet | 対象のワークシート                     |
| keyword             | String    | 検索キーワード                         |
| col（省略可）       | Long      | 対象列番号（省略時は 1 = A列）         |
| matchMode（省略可） | Long      | 一致モード（省略時は 1 = 部分一致）    |

### matchMode の種類

| 値 | モード   | 判定内容                       |
|----|----------|--------------------------------|
| 1  | 部分一致 | keyword を含む                 |
| 2  | 完全一致 | keyword と同一                 |
| 3  | 前方一致 | keyword で始まる               |
| 4  | 後方一致 | keyword で終わる               |

※ すべて大文字小文字を区別しない。上記以外の値は部分一致として扱う。

# 出力（日本語）

- 型: なし（Sub）
- 内容: 一致したセルの値のみを `Debug.Print` で出力する。戻り値はない。
- エラー値（#N/A など）のセルはスキップする。
- 走査範囲は指定列の 1 行目から最終使用行まで。

# 使用例

```vba
Dim ws As Worksheet
Set ws = ThisWorkbook.Sheets("Sheet1")

Grep ws, "りんご"        ' A列から部分一致で検索
Grep ws, "A001", 2       ' B列から検索
Grep ws, "山田", 1, 2    ' A列を完全一致で検索
Grep ws, "株式会社", 3, 3 ' A列を前方一致で検索
```

出力例（イミディエイトウィンドウ）:

```text
りんご
青りんご
```
